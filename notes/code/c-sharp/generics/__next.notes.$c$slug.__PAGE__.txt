5:T5e4,<h2 id="generic-method-argument-types">Generic Method Argument Types</h2>
<p>Methods in C# can be generic, which means they can work with different types without the need to write separate methods for each type.</p>
<p>The types specified in the angle brackets <code>&#x3C;></code> are placeholders that get replaced with actual types when the method is called.</p>
<pre><code class="language-csharp">public class GenericExample
{
    public T FindMax&#x3C;T>(T first, T second) 
    where T : IComparable&#x3C;T>
    {
        return first.CompareTo(second) > 0 ? first : second;
    }
}

class Program
{
    static void Main(string[] args)
    {
        GenericExample example = new GenericExample();

        // Using with integers
        int maxInt = example.FindMax(10, 20);
        // Output: Max integer: 20
        Console.WriteLine($"Max integer: {maxInt}"); 

        // Using with doubles
        double maxDouble = example.FindMax(3.14, 2.71);
        // Output: Max double: 3.14
        Console.WriteLine($"Max double: {maxDouble}"); 

        // Using with strings
        string maxString = example.FindMax("apple", "banana");
        // Output: Max string: banana
        Console.WriteLine($"Max string: {maxString}"); 
    }
}
