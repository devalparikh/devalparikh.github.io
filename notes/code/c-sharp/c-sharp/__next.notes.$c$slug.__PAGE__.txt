32:T2331,<h1 id="background">Background</h1>
<ul>
<li><a href="/notes/code/c-sharp/c-sharp/#type">Type</a> Safe language / strongly typed</li>
<li>Benefits
<ul>
<li>Web apps, mobile apps, games</li>
<li>Microservices, enterprise</li>
<li>Raspberry pie</li>
<li>Cross platform</li>
</ul>
</li>
<li>c# code -compiled-> CIL -executed as machine code-> CLR (common language runtime)</li>
</ul>
<h1 id="basics"><strong>Basics</strong></h1>
<h2 id="terms">Terms</h2>
<ul>
<li><strong>Type</strong> - blueprint defines structure (value type and reference type)
<ul>
<li><strong>Class</strong> - reference type</li>
<li><strong>(Member</strong> - general term refers to elements in a class (such as: fields, methods, etc))</li>
<li><strong>Field</strong> - variable in a class (assigned a type)</li>
<li><strong>Property</strong> - mechanism to read/write/compute on private field (include accessor methods) (getters/setters)</li>
<li><strong>Attribute</strong> - metadata applied to classes, methods, properties (not data storage, but metadata)</li>
</ul>
</li>
</ul>
<h2 id="type">Type</h2>
<ul>
<li><strong>Value Type</strong> (primitive)
<ul>
<li>Kinda like primitives</li>
<li>Memory: allocated on stack</li>
<li>Garbage Collection: not managed</li>
<li>Upon assignment to another variable: copy value</li>
<li><code>null</code>: not allowed (?)</li>
<li><strong>Examples</strong>: <code>int</code>, <code>float</code>, <code>bool</code>, <code>char</code>, <code>struct</code>, <code>enum</code></li>
</ul>
</li>
<li><strong>Reference Type</strong> (class)
<ul>
<li>Memory: allocated on heap</li>
<li>Garbage Collection: managed</li>

<h1 id="keywords">Keywords</h1>
<p><strong>General</strong></p>
<p><code>public</code> - Accessible from any other code in the same assembly or referencing assembly <code>private</code> - Accessible only within the same class or struct
<code>protected</code> - Accessible within the same class and derived classes
<code>internal</code> - Accessible within the same assembly
<code>static</code> - Belongs to the type itself, not to a specific object instance</p>
<p><strong>Classes</strong></p>
<p><code>abstract</code> - Cannot be instantiated, may contain abstract methods
<code>sealed</code> - Cannot be inherited from</p>
<p><code>partial</code> - Allows splitting a class definition across multiple files
<code>virtual</code> - Can be overridden by derived classes
<code>override</code> - Implements a method of an abstract class or overrides a virtual method
<code>new</code> - Hides an inherited member from a base class</p>
<p><code>class</code> - Defines a reference type
<code>struct</code> - Defines a value type (stored in <strong>stack</strong>)</p>
<ul>
<li>details
<ul>
<li>good for small</li>
<li>good for immutable value types</li>
<li>improves performance (stack memory)</li>
<li>saves memory (stack memory)</li>
<li>copy by value
<code>record</code> - Defines an <strong>immutable</strong> reference type with value-based equality (immutable)
<code>interface</code> - Defines a contract that classes can implement
<code>enum</code> - Defines a set of named constants</li>
</ul>
</li>
</ul>
<p><strong>Fields</strong></p>
<p><code>readonly</code> - Can only be assigned in declaration or constructor (immutable)</p>
<ul>
<li>details
<ul>
<li>compiler optimization
<code>const</code> - Compile-time constant (immutable)</li>
</ul>
</li>
<li>details
<ul>
<li>saves memory</li>
<li>compiler optimization</li>
<li>no stack or heap
<code>volatile</code> - Indicates that a field might be modified by multiple threads
<code>fixed</code> - Used in unsafe code to prevent the garbage collector from relocating a variable <code>event</code> - Declares an event</li>
</ul>
</li>
</ul>

<p><code>virtual</code> - Can be overridden by derived classes

<code>sealed</code> - Cannot be overridden further in derived classes
<code>new</code> - Hides an inherited member from a base class
<code>async</code> - Method contains asynchronous operations
<code>extern</code> - Method is implemented externally
<code>partial</code> - Allows splitting a method definition across multiple files
<code>unsafe</code> - Allows use of pointer types within the method
<code>ref</code> - Parameter is passed by reference
<code>in</code> - Parameter is passed by reference, but cannot be modified
<code>out</code> - Parameter is passed by reference and must be assigned before method returns</p>

<h1 id="implicit-operator">Implicit Operator</h1>
<p>Allows a method to return multiple types of objects</p>
<pre><code class="language-csharp">public class Result&#x3C;T>
{
    public T Value { get; }
    public Error Error { get; }
    public bool IsSuccess { get; }

    private Result(T value)
    {
        Value = value;
        IsSuccess = true;
    }

    private Result(Error error)
    {
        Error = error;
        IsSuccess = false;
    }

	// implicit operators
    public static implicit operator Result&#x3C;T>(T value) 
    => new Result&#x3C;T>(value);
    
    public static implicit operator Result&#x3C;T>(Error error) 
    => new Result&#x3C;T>(error);
}

public class Error
{
    public string Code { get; }
    public string Message { get; }

    public Error(string code, string message)
    {
        Code = code;
        Message = message;
    }
}

// usage example
public class Example 
{
	public Result&#x3C;User> GetUser(Guid id)
	{
	    if (_users.TryGetValue(id, out var user))
	    {
		    // Implicitly converted to Result&#x3C;User>
	        return user;
	    }
		// Implicitly converted to Result&#x3C;User>
	    return new Error("NotFound", "User not found");
	}
}

<h1 id="best-practices">Best Practices</h1>

<h2 id="naming-convention">Naming Convention</h2>
<ul>
<li><code>PascalCase</code> for types, namespaces, and all public members</li>
<li><code>camelCase</code> for method parameters and local variables</li>
<li><code>_camelCase</code> for private private instance fields</li>
<li><code>PascalCase</code> for constant names, both fields and local constants</li>
<li><code>s_camelCase</code> private static</li>
<li><code>t_camelCase</code> private thread static</li>
<li>Interface start with <code>I</code></li>
<li>Attribute types end with the word <code>Attribute</code></li>
<li>Namespace end with the word <code>Namespace</code></li>
</ul>
